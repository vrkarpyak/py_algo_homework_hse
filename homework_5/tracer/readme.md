Решение:

Декоратор tracer показывает, как рекурсивная функция вызывает сама себя и возвращает результат.
В переменной depth хранится текущая глубина вызова. В начале она равна 0.
Сначала wrapper собирает имя функции и ее аргументы в строку. Затем печатает вход в функцию.
Перед каждой строкой ставится по два пробела на каждый уровень глубины. Поэтому чем глубже рекурсия, тем больше отступ.

После печати входа глубина увеличивается на 1. Далее вызывается исходная функция:
result = func(*args, **kwargs)
Когда функция завершает работу, глубина уменьшается на 1 и печатается возврат с результатом. Затем wrapper возвращает этот же результат.
nonlocal depth нужен, чтобы внутренняя функция wrapper могла изменять переменную depth из tracer.
try и finally нужны, чтобы уменьшать глубину даже при исключении. В этом случае ошибка передается дальше, а строка возврата с результатом не печатается, потому что результата нет.
wraps сохраняет имя исходной функции и другую служебную информацию о ней.
Для примера используется факториал:
factorial(0) = 1
factorial(n) = n * factorial(n - 1)

Декоратор не меняет вычисление факториала, а только печатает ход рекурсии.


Оценка сложности:
Пусть k - количество вызовов исходной функции, а h - максимальная глубина рекурсии.
Для каждого вызова tracer печатает один вход и один возврат, если вызов закончился успешно. При подсчете строк вывода это O(k) дополнительной работы.
Отступы содержат по два пробела на каждый уровень. Поэтому печать всех символов может требовать больше времени: для factorial(n) суммарная длина отступов составляет O(n²).
Дополнительная память для служебных данных одного вызова невелика. Одновременно активны вызовы до глубины h, поэтому стек вызовов занимает O(h) памяти, не считая память для хранения самого вывода.
Для factorial(n) высота стека составляет O(n). Декоратор не создает отдельный список всех вызовов.


Визуализация работы алгоритма:
Рассмотрим factorial(3).
Сначала вызывается factorial(3), затем factorial(2), factorial(1) и factorial(0).

Цепочка вызовов:
factorial(3)
  factorial(2)
    factorial(1)
      factorial(0)

Вызов factorial(0) возвращает 1. Затем по очереди возвращаются остальные вызовы.

Вывод:
Вход: factorial(3)
  Вход: factorial(2)
    Вход: factorial(1)
      Вход: factorial(0)
      Возврат: factorial(0) = 1
    Возврат: factorial(1) = 1
  Возврат: factorial(2) = 2
Возврат: factorial(3) = 6

Видно, что при входе отступ увеличивается, а при возврате уменьшается.


Тесты:
Проверяются следующие случаи:
факториал от нуля;
точный порядок входов и возвратов для factorial(3);
повторные вызовы без накопления лишней глубины;
другая функция с декоратором;
позиционные и именованные аргументы;
ветвящаяся рекурсия на числах Фибоначчи;
функция с результатом None;
восстановление глубины после ошибки;
факториал от единицы;
несколько уровней рекурсии;
восстановление глубины после ошибки внутри рекурсии;
сохранение исходного типа исключения;
сохранение имени исходной функции.
