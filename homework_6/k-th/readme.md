Решение:

Используем алгоритм quickselect. Он похож на quick sort, но не сортирует весь массив.

Нужно найти k-й по величине элемент. Например, если k = 2, нужен второй по величине элемент.

Сначала создаем копию массива, чтобы исходный список не изменялся.

Если бы массив был отсортирован по возрастанию, нужный элемент стоял бы на индексе:

target = len(arr) - k

На самом деле сортировать массив не будем. Индекс target нужен только для поиска.

Выбираем опорное число pivot из середины текущего диапазона.

Затем переставляем элементы так, чтобы они разделились на три части:

числа меньше pivot;
числа равные pivot;
числа больше pivot.

Для этого используем три индекса:

less - начало части с элементами, равными pivot;
i - элемент, который сейчас рассматриваем;
greater - конец части с элементами, равными pivot.

После разбиения понятно, где в отсортированном массиве находились бы числа, равные pivot.

Если target попал в эту часть, возвращаем pivot.

Если target находится левее, продолжаем искать только в левой части.

Если target находится правее, продолжаем искать только в правой части.

Повторяем, пока нужный элемент не будет найден.

Таким образом, мы каждый раз отбрасываем часть массива, в которой ответа точно нет. Полная сортировка не выполняется.

Повторяющиеся значения учитываются как отдельные элементы. Например, в массиве [5, 5, 4] второй по величине элемент равен 5.


Оценка сложности:

Средняя временная сложность - O(n), потому что на каждом шаге просматриваем только текущую часть массива и обычно существенно уменьшаем область поиска.

В худшем случае временная сложность - O(n²), если опорные элементы постоянно дают очень неравномерное разбиение.

Дополнительная память - O(n), потому что создается копия исходного массива.

Само разбиение выполняется на месте в этой копии и использует только несколько переменных. Рекурсия не используется.


Визуализация работы алгоритма:

Пример:

nums = [3, 2, 1, 5, 6, 4]
k = 2

Длина массива равна 6.

Ищем элемент, который при сортировке по возрастанию стоял бы на индексе:

target = 6 - 2 = 4

Исходный массив:

[3, 2, 1, 5, 6, 4]

Шаг 1:

left = 0, right = 5
pivot = 1

После разбиения:

[1, 2, 5, 6, 4, 3]

Число 1 находится на индексе 0.

Искомый индекс 4 правее, поэтому продолжаем поиск справа.

Шаг 2:

left = 1, right = 5
pivot = 6

После разбиения:

[1, 2, 5, 4, 3, 6]

Число 6 находится на индексе 5.

Искомый индекс 4 левее, поэтому продолжаем поиск слева.

Шаг 3:

left = 1, right = 4
pivot = 5

После разбиения:

[1, 2, 4, 3, 5, 6]

Число 5 оказалось на индексе 4.

Это наш target.

Ответ: 5


Второй пример:

nums = [3, 2, 3, 1, 2, 4, 5, 5, 6]
k = 4

Ищем индекс:

target = 9 - 4 = 5

После нескольких разбиений число 4 оказывается на индексе 5.

Ответ: 4


Тесты:

Проверяются несколько разных случаев:
первый пример из условия;
второй пример из условия с повторениями;
один элемент;
два элемента;
поиск самого большого числа;
поиск самого маленького числа;
повторяющиеся значения;
все значения одинаковые;
отрицательные числа;
нули;
уже отсортированный массив;
массив в обратном порядке;
проверка, что исходный список не изменяется;
длинный массив из одинаковых чисел;
длинный отсортированный массив;
несколько случайных коротких массивов с проверкой ответа для разных k.
