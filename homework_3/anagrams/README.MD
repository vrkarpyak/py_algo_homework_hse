Решение:

Создаем пустой словарь groups.

Проходим список слов по одному.

Для каждого слова сортируем его буквы и получаем ключ.

Например:

eat -> aet
tea -> aet
ate -> aet

У всех этих слов получается одинаковый ключ aet, поэтому они должны попасть в одну группу.

В словаре groups храним:

ключ -> список слов с таким ключом

Если такого ключа в словаре еще нет, создаем для него пустой список.

После этого добавляем текущее слово в нужную группу.

Например:

groups = {
    "aet": ["eat", "tea", "ate"],
    "ant": ["tan", "nat"],
    "abt": ["bat"]
}

В конце возвращаем все группы из словаря.


Оценка сложности:

Пусть n - количество слов, а m - максимальная длина слова.

Для каждого слова сортируем его буквы.

Сортировка одного слова занимает O(m log m).

Поэтому временная сложность - O(n * m log m).

Пространственная сложность - O(n * m), потому что в словаре хранятся ключи и все слова, распределенные по группам.


Визуализация работы алгоритма:

Пример:

strs = ["eat", "tea", "tan", "ate", "nat", "bat"]

В начале:

groups = {}


Первое слово:

word = "eat"

После сортировки:

key = "aet"

Такого ключа еще нет.

Создаем новую группу и добавляем слово:

groups = {
    "aet": ["eat"]
}


Второе слово:

word = "tea"

После сортировки:

key = "aet"

Такой ключ уже есть.

Добавляем слово в существующую группу:

groups = {
    "aet": ["eat", "tea"]
}


Третье слово:

word = "tan"

После сортировки:

key = "ant"

Такого ключа еще нет.

Создаем новую группу:

groups = {
    "aet": ["eat", "tea"],
    "ant": ["tan"]
}


Четвертое слово:

word = "ate"

После сортировки:

key = "aet"

Добавляем в первую группу:

groups = {
    "aet": ["eat", "tea", "ate"],
    "ant": ["tan"]
}


Пятое слово:

word = "nat"

После сортировки:

key = "ant"

Добавляем во вторую группу:

groups = {
    "aet": ["eat", "tea", "ate"],
    "ant": ["tan", "nat"]
}


Шестое слово:

word = "bat"

После сортировки:

key = "abt"

Создаем новую группу:

groups = {
    "aet": ["eat", "tea", "ate"],
    "ant": ["tan", "nat"],
    "abt": ["bat"]
}


В результате получаем группы:

["eat", "tea", "ate"]
["tan", "nat"]
["bat"]

Порядок самих групп в ответе не важен. Главное, чтобы все анаграммы находились в одной группе.


Тесты:

Проверяются несколько разных случаев:

пример из условия;

список из одного слова;

пустой список;

слова без анаграмм;

случай, когда все слова являются анаграммами;

одинаковые слова;

пустые строки;

несколько групп разного размера;

проверка, что исходный список не изменяется.
