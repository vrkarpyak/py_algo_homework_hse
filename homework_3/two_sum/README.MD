Решение:

Создаем пустой словарь seen.

Проходим массив слева направо.

Для каждого элемента number с индексом index считаем число, которого не хватает до суммы k:

needed = k - number

В словаре seen храним уже просмотренные числа и их индексы.

Например:

seen = {1: 0, 3: 1}

Это значит, что число 1 встретилось на индексе 0, а число 3 встретилось на индексе 1.

Для текущего числа сначала проверяем, есть ли needed в словаре seen.

Если needed уже есть, значит нужная пара найдена. Возвращаем индекс числа из словаря и текущий индекс.

Если needed в словаре нет, сохраняем текущее число и его индекс:

seen[number] = index

Сначала проверяем needed, и только потом добавляем текущее число в seen. Поэтому один и тот же элемент массива не может быть использован дважды.

Так как в словаре хранятся только уже просмотренные элементы, найденный в словаре индекс всегда меньше текущего. Поэтому индексы сразу возвращаются в порядке возрастания.


Оценка сложности:

Временная сложность - O(n), потому что массив проходится один раз.

Проверка наличия элемента в словаре и добавление элемента в словарь в среднем выполняются за O(1).

Пространственная сложность - O(n), потому что в худшем случае в словаре seen будут храниться почти все элементы массива.


Визуализация работы алгоритма:

Пример:

arr = [1, 3, 4, 10]
k = 7

В начале:

seen = {}

Первый элемент:

index = 0
number = 1
needed = 7 - 1 = 6

Числа 6 в seen нет.

Сохраняем число 1 и его индекс:

seen = {1: 0}


Второй элемент:

index = 1
number = 3
needed = 7 - 3 = 4

Числа 4 в seen нет.

Сохраняем число 3 и его индекс:

seen = {1: 0, 3: 1}


Третий элемент:

index = 2
number = 4
needed = 7 - 4 = 3

Число 3 уже есть в seen:

seen[3] = 1

Значит, число 3 находится на индексе 1, а число 4 находится на индексе 2.

Проверяем:

arr[1] + arr[2] = 3 + 4 = 7

Возвращаем:

1 2


Второй пример:

arr = [5, 5, 1, 4]
k = 10

Первый элемент:

index = 0
number = 5
needed = 10 - 5 = 5

В seen числа 5 еще нет.

Сохраняем:

seen = {5: 0}


Второй элемент:

index = 1
number = 5
needed = 10 - 5 = 5

Число 5 уже есть в seen на индексе 0.

Проверяем:

arr[0] + arr[1] = 5 + 5 = 10

Возвращаем:

0 1


Тесты:

Проверяются несколько разных случаев:

первый пример из условия: [1, 3, 4, 10], k = 7;

второй пример из условия: [5, 5, 1, 4], k = 10;

массив из двух элементов;

пара элементов на краях массива;

пара элементов в середине массива;

массив с отрицательными числами;

массив с нулем;

два одинаковых значения;

проверка, что исходный массив не изменяется.
