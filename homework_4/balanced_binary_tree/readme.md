Решение:

Нужно проверить, что для каждого узла высоты левого и правого поддеревьев отличаются не больше чем на 1.
Используем рекурсию. Для каждого узла функция height находит высоту его поддерева.
Высота пустого дерева равна 0. Высота узла равна максимальной высоте двух его поддеревьев плюс 1.
Сначала находим высоту левого поддерева, затем правого.
Если разница между ними больше 1, дерево не сбалансировано. В этом случае функция возвращает -1.
Число -1 здесь означает, что найдено нарушение. Оно не может быть настоящей высотой дерева, потому что высота не бывает отрицательной.
Если одно из поддеревьев уже вернуло -1, дальше проверять его не нужно. Сразу возвращаем -1 выше по рекурсии.
Если разница высот не больше 1, возвращаем высоту текущего поддерева.
В конце проверяем результат для корня. Если он не равен -1, возвращаем True. Иначе False.
Проверка работает для любого бинарного дерева. Значения узлов не обязаны соответствовать правилам BST, потому что сбалансированность зависит только от формы дерева.
Функция build_tree используется для создания дерева из списка значений по уровням. None обозначает отсутствие узла.


Оценка сложности:

Пусть n - количество узлов дерева, h - его высота.
Временная сложность - O(n), потому что высота каждого поддерева вычисляется только один раз. В худшем случае будут просмотрены все n узлов.
Дополнительная память - O(h), потому что во время рекурсивных вызовов в памяти находится цепочка узлов от корня до текущего узла.
Если дерево примерно сбалансировано, высота h = O(log n).
Если дерево вытянуто в цепочку, высота h = O(n). Тогда память в худшем случае равна O(n).
Сама функция проверки не создает дополнительных массивов или списков. Функция build_tree отдельно использует O(n) памяти, потому что создает узлы и список для построения дерева.


Визуализация работы алгоритма:

Первый пример - сбалансированное дерево:

        4
       / \
      2   6
     / \ / \
    1  3 5  7

У листьев 1, 3, 5, 7 высота равна 1.

У узла 2 высоты левого и правого поддеревьев равны 1 и 1. Разница равна 0. Высота самого узла 2 равна 2.

У узла 6 ситуация такая же. Его высота равна 2.

У корня 4 высоты поддеревьев равны 2 и 2. Разница равна 0.

Все узлы подходят под условие. Ответ True.


Второй пример - несбалансированное дерево:

        1
       /
      2
     /
    3
   /
  4

Высота узла 4 равна 1.

У узла 3 высоты поддеревьев равны 1 и 0. Разница равна 1, поэтому его высота равна 2.

У узла 2 высоты поддеревьев равны 2 и 0. Разница равна 2.

Узел 2 не удовлетворяет условию. Функция возвращает -1, и результат для всего дерева False.


Третий пример - ошибка внутри дерева:

          1
         / \
        2   3
       /     \
      4       6
     /         \
    5           7

У корня слева и справа высота равна 3, поэтому разница равна 0.

Но у узла 2 слева высота 2, а справа 0. Разница равна 2.

Значит, дерево несбалансировано, хотя высоты двух поддеревьев корня одинаковые.

Ответ False. Поэтому важно проверять каждый узел, а не только корень.


Четвертый пример - допустимая разница высот:

        1
       / \
      2   3
     /
    4

У корня высоты поддеревьев равны 2 и 1. Разница равна 1.

У других узлов разница тоже не больше 1.

Ответ True.


Тесты:

Проверяются несколько разных случаев:
пустое дерево;
дерево из одного узла;
дерево из двух узлов слева и справа;
полное сбалансированное дерево;
сбалансированное дерево с разницей высот 1;
цепочка только из левых узлов;
цепочка только из правых узлов;
нарушение условия у корня;
нарушение условия внутри поддерева;
случай, когда у корня высоты равны, но внутри есть нарушение;
отрицательные значения и ноль;
повторяющиеся значения;
бинарное дерево без порядка BST;
повторная проверка одного дерева без изменения его структуры.
