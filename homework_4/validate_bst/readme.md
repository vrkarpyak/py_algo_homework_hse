Решение:

Нужно проверить, что бинарное дерево является деревом поиска.

В правильном BST все значения в левом поддереве меньше значения узла, а все значения в правом поддереве больше.

При этом сравнивать узел только с его непосредственными детьми недостаточно. Нужно учитывать и значения узлов выше по дереву.

Поэтому проверка работает через рекурсию.

Для каждого узла передаем два ограничения: minimum и maximum.

minimum - значение, больше которого должен быть текущий узел.
maximum - значение, меньше которого должен быть текущий узел.

У корня ограничений нет, поэтому сначала передаем None и None.

Если текущий узел равен None, это пустое поддерево. Оно не нарушает правила BST, поэтому возвращаем True.
Если значение узла меньше или равно minimum либо больше или равно maximum, возвращаем False.
Иначе рекурсивно проверяем оба поддерева.
Для левого поддерева верхней границей становится значение текущего узла.
Для правого поддерева нижней границей становится значение текущего узла.

Если обе проверки вернули True, значит дерево правильное.

Одинаковые значения не допускаются, как и в предыдущем задании на BST.

Функция build_tree нужна только для удобного создания произвольных деревьев из списка, в том числе неправильных. Для проверки достаточно функции is_valid_bst.


Оценка сложности:

Пусть n - количество узлов, h - высота дерева.
Временная сложность - O(n), потому что в худшем случае проверяем каждый узел один раз.
Дополнительная память - O(h), потому что рекурсивные вызовы занимают память в зависимости от высоты дерева.
Для сбалансированного дерева h = O(log n).
Если дерево вытянуто в цепочку, h = O(n), и память рекурсии в худшем случае равна O(n).
Функция build_tree дополнительно использует список узлов и занимает O(n) памяти. Эта память нужна для создания дерева из входной строки, а не для самого алгоритма проверки.


Визуализация работы алгоритма:

Первый пример - правильное BST:

        4
       / \
      2   6
     / \ / \
    1  3 5  7

У корня 4 ограничений нет.

Для узла 2 диапазон: меньше 4.

Для узла 1 диапазон: меньше 2.

Для узла 3 диапазон: больше 2 и меньше 4.

Для узла 6 диапазон: больше 4.

Для узла 5 диапазон: больше 4 и меньше 6.

Для узла 7 диапазон: больше 6.

Все условия выполняются, ответ True.


Второй пример - неправильное BST:

        5
       / \
      1   4
         / \
        3   6

Значение 4 находится справа от 5, но 4 меньше 5.

Для всего правого поддерева корня значения должны быть больше 5.

Узел 4 нарушает это правило, ответ False.


Третий пример - ошибка в глубине дерева:

        10
       /  \
      5    15
          /  \
         6    20

Узел 6 меньше своего родителя 15, на первый взгляд все хорошо.

Но он находится в правом поддереве узла 10 и обязан быть больше 10.

Поэтому для узла 6 действует диапазон: больше 10 и меньше 15.

Число 6 не входит в этот диапазон, ответ False.


Тесты:

Проверяются несколько разных случаев:
пустое дерево;
дерево из одного узла;
правильное дерево из семи узлов;
неправильный непосредственный левый или правый ребенок;
ошибка внутри левого и правого поддерева;
одинаковые значения у родителя и ребенка;
одинаковые значения у узла и его предка;
дерево только с левыми дочерними узлами;
дерево только с правыми дочерними узлами;
отрицательные числа и ноль;
нарушение BST среди отрицательных чисел;
глубокое нарушение границ в правом поддереве.
